# Auditoría de Investigación — registro de la sesión de navegador

> **Quién escribe aquí:** solo la sesión que prueba la Preview en un navegador real (o tú, copiando su informe).
> **Quién NO escribe aquí:** la sesión de código. Ella responde en `docs/auditoria-resoluciones.md` (mismo número de hallazgo) para que nunca se pisen los cambios.
> Si las sesiones no comparten el repositorio, copia el bloque «Formato de hallazgo» tal cual en el chat de código.

## Formato de hallazgo (copiar y rellenar; un bloque por problema)

```
### H-001 · <título corto>
- Gravedad: crítica | alta | media | baja
- Pestaña / pantalla: <p. ej. Investigación › Descubrir oportunidades>
- Preview y commit probados: <URL> · <sha>
- Pasos para reproducir: 1) … 2) … 3) …
- Resultado observado: …
- Resultado esperado: …
- Datos reales implicados: <búsqueda, país, vídeo/URL, fecha y hora>  (no inventar; si no se midió, escribir «no medido»)
- Cuota gastada en la prueba (unidades): <n>
- Captura: <ruta o enlace>
```
